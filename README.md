# EN Clinic Lab App / 開業ラボ

クリニック承継・売却・開業支援向けのVite + Reactアプリです。

## 機能

- TOPページ
- 売却価格シミュレーター
- コラム一覧 / 詳細
- セミナー一覧 / 申込
- 無料相談フォーム
- 申込受付画面
- プライバシーポリシー
- 固定CTA
- レスポンシブ対応

## ローカル起動

```bash
npm install
npm run dev
```

## Vercel設定

- Framework Preset: Vite
- Build Command: npm run build
- Output Directory: dist
- Install Command: npm install
- Node.js: 20.x
